# Практична робота 5: Розробка віджетів у Flutter 

## Опис
Додаток з власною бібліотекою кастомних віджетів, анімаціями, `CustomPaint` та State Management.

## Бонусні завдання (+4 бали)
1. **Advanced Animations (+1)**: Використання `AnimationController` з плавними кривими.
2. **Custom Paint Widgets (+1)**: Власний віджет малювання `CustomChartWidget`.
3. **Accessibility (+1)**: Підтримка `Semantics` для Screen Readers.
4. **Performance (+1)**: Оптимізація дерева віджетів за допомогою `RepaintBoundary`.
